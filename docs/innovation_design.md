# LF-Loc 创新点增强设计文档

## 1. 背景与问题

当前 LF-Loc 的基础框架是一个比较清晰的轻量分割流水线：

```text
输入图像 -> 冻结视觉主干 -> 轻量 FPN -> FBAA -> 分割头 -> 伪造区域 mask
```

这个框架作为工程 baseline 是合理的，但如果只概括成“冻结大模型 backbone + 轻量分割头”，创新性还不够强。近两年很多检测方法已经在使用预训练视觉编码器、adapter 或参数高效微调，因此 LF-Loc 需要强调更贴近人脸伪造定位任务本身的线索，而不只是强调模型轻量。

建议把创新点加强到三个层面：

1. 伪造边界感知定位。
2. 空间-频域特征协同。
3. 面向资源受限场景的参数高效训练。

这三个点组合起来，可以把 LF-Loc 从“普通轻量分割模型”升级成“面向伪造痕迹定位的轻量化框架”。

## 2. 改进后的整体框架

推荐将升级版 LF-Loc 描述为：

```text
RGB 图像
  |-> 冻结 DINOv2/CLIP backbone -> 语义特征
  |-> 高频残差分支 -> 伪影特征

语义特征 + 伪影特征
  -> 轻量特征融合 neck
  -> 伪造边界感知注意力模块
  -> 分割解码头
  -> mask 预测 + 边界预测 + 图像级真伪预测
```

模型仍然保持“冻结预训练视觉主干，只训练轻量模块”的思路。训练部分主要包括特征融合模块、边界感知注意力模块、分割头，以及可选的分类头。

## 3. 主创新点一：伪造边界感知注意力模块

### 3.1 核心想法

人脸伪造区域的可靠线索往往集中在融合边界附近，例如颜色不连续、纹理断层、局部高频异常等。相比只在分割结果上额外加一个边界损失，更强的做法是：让模型显式预测边界，并把边界响应图作为空间注意力来反向引导 mask 预测。

该模块可以命名为：

```text
FBAA：Forgery Boundary-Aware Attention，伪造边界感知注意力模块
```

### 3.2 模块设计

给定特征图 `F`，FBAA 输出：

- `B_pred`：预测的伪造边界 logits。
- `A_boundary`：由边界预测得到的空间注意力图。
- `F_refined`：经过边界注意力增强后的特征图。

一个可实现的简化版本如下：

```text
F
 |-> 边界分支 -> B_pred -> sigmoid -> A_boundary
 |-> 主分支

F_refined = F + F * A_boundary
```

边界分支可以保持轻量：

```text
Conv 3x3 -> BN -> ReLU -> Conv 1x1
```

边界监督可以由 GT mask 自动生成，例如对真实 mask 使用 Sobel 或 Laplacian 算子得到边界图。

### 3.3 损失函数

完整损失可以写成：

```text
L_total = lambda_seg * (L_bce + L_dice)
        + lambda_boundary * L_boundary
        + lambda_cls * L_cls
```

各项含义：

- `L_bce`：mask 的逐像素二元交叉熵损失。
- `L_dice`：Dice 损失，用于缓解前景区域较小导致的类别不平衡。
- `L_boundary`：预测边界图与 GT 边界图之间的损失，可以使用 BCE 或 MSE。
- `L_cls`：可选的图像级真伪分类损失。

### 3.4 预期贡献

这个设计把“边界”从一个附加监督项升级成完整机制：

- 有边界监督。
- 有边界预测。
- 有边界注意力。
- mask 预测受边界响应引导。

因此它比简单加 Sobel boundary loss 更有方法创新性。

## 4. 主创新点二：空间-频域特征协同

### 4.1 核心想法

Deepfake 伪造痕迹不只体现在语义层面，也体现在高频残差、压缩伪影、局部纹理不连续和上采样痕迹中。如果模型只依赖 RGB 图像经过 ViT backbone 后的语义特征，可能会忽略这些细粒度伪影。

因此可以给 LF-Loc 增加一个轻量高频分支：

```text
RGB 图像 -> 固定高通滤波器 -> 残差图 -> 小型 CNN -> 伪影特征
```

这个分支必须保持很小，避免破坏“轻量化”的核心定位。

### 4.2 可选高频输入

可以考虑以下高频线索：

- Sobel 梯度。
- Laplacian 响应。
- SRM 风格高通滤波器。
- DCT 或块 DCT 残差特征。
- NPR 风格邻近像素关系图。

第一版最推荐 Sobel + Laplacian，因为实现简单、依赖少、调试成本低。

### 4.3 融合方式

高频伪影特征可以和 backbone/FPN 的语义特征融合：

```text
F_sem = FPN(backbone(image))
F_art = ArtifactBranch(image)
F_fused = Conv1x1(concat(F_sem, F_art))
```

之后将 `F_fused` 输入 FBAA 和分割头。

### 4.4 预期贡献

这个设计给 LF-Loc 增加了更符合伪造检测任务的线索来源：

- 冻结 backbone 提供语义和结构表征。
- 高频分支提供局部伪影线索。
- FBAA 利用边界注意力聚焦定位区域。

这样 LF-Loc 就不再只是一个普通的 ViT 分割头，而是一个结合语义、伪影和边界的伪造定位模型。

## 5. 主创新点三：参数高效伪造定位

### 5.1 核心想法

LF-Loc 的应用场景是资源受限条件下的人脸伪造定位，因此需要明确强调“冻结多少参数、训练多少参数、用多低的成本达到怎样的定位效果”。

训练策略：

- 冻结 DINOv2/CLIP backbone。
- 只训练 FPN、高频分支、FBAA、分割头和可选分类头。
- 将可训练参数量控制在较小范围内，例如 2M 到 5M。

### 5.2 实验设计

建议做以下对比：

| 实验变体 | 目的 |
| --- | --- |
| 只训练 segmentation head | 最小适配 baseline |
| 训练 FPN + head | 当前轻量 baseline |
| 训练 FPN + FBAA + head | 验证边界注意力贡献 |
| 训练 FPN + 高频分支 + FBAA + head | 验证完整 LF-Loc |
| 微调 backbone | 对比精度收益与训练成本 |

需要记录的指标：

- IoU。
- Dice。
- F1@pixel。
- 如果加入分类头，记录 AUC。
- 可训练参数量。
- GPU 显存占用。
- 单个 epoch 训练时间。

### 5.3 预期贡献

这部分支撑 LF-Loc 的轻量化主张：模型不只是能定位，还要证明它在训练成本和参数效率上有优势。

## 6. 可选增强点：压缩鲁棒一致性

### 6.1 核心想法

人脸伪造定位对压缩很敏感。FF++ 本身包含不同压缩等级，真实社交媒体中的图像和视频也经常会被二次压缩。

可以加入一致性约束：

```text
原图 -> 预测 P1
压缩后图像 -> 预测 P2
L_consistency = distance(P1, P2)
```

目标是让模型在 JPEG 压缩、轻微模糊等退化条件下仍然输出稳定的定位 mask。

### 6.2 实用版本

第一版不一定要直接做 consistency loss，可以先做轻量实验：

- 在数据增强中加入随机 JPEG 压缩。
- 测试从 c23 到 c40 时性能下降多少。
- 后续再考虑加入一致性损失。

这个点适合作为扩展实验，不建议作为第一优先级。

## 7. 可写进报告的创新点表述

建议将 LF-Loc 的创新点概括为：

> 本文提出 LF-Loc，一种面向资源受限场景的人脸伪造区域定位框架。该方法冻结预训练视觉编码器，仅训练轻量级定位适配模块；进一步设计伪造边界感知注意力模块，利用显式边界预测引导伪造区域分割；同时引入轻量高频伪影分支，将语义特征与局部伪造痕迹相结合。通过定位精度、可训练参数量和消融实验，验证该方法在轻量化与像素级可解释性之间的有效权衡。

可以拆成论文/报告里的三条贡献：

1. 提出一种冻结预训练视觉主干的轻量伪造定位框架，在较少可训练参数下实现像素级伪造区域预测。
2. 设计伪造边界感知注意力模块，通过边界预测、边界监督和边界注意力增强模型对融合边界的定位能力。
3. 引入轻量高频伪影分支，将语义特征与局部频域残差信号融合，提高模型对细粒度伪造痕迹的感知能力。

## 8. 实现路线

### 阶段一：稳定 baseline

- 保留当前冻结 backbone 流水线。
- 修复 config 加载和环境兼容问题。
- 增加 dataloader、model forward、loss、metrics 的小型自测。

### 阶段二：实现真实 FBAA

- 将当前 identity 版本的 FBAA 替换成真实边界分支。
- 根据需要让模块返回边界 logits。
- 在 loss 中加入 GT boundary 生成逻辑。
- 增加消融开关 `w_fbaa`。

### 阶段三：加入高频分支

- 实现固定 Sobel/Laplacian 特征提取。
- 增加小型 CNN 伪影编码器。
- 将高频特征与 FPN 特征融合。
- 增加消融开关 `w_freq`。

### 阶段四：加入分类头

- 增加全局池化分类头。
- 扩展 dataset 输出图像级 label。
- 在评估中加入 AUC。

### 阶段五：开展实验

- FF++ 主实验。
- FBAA 消融。
- Dice loss 消融。
- 高频分支消融。
- 冻结 backbone 与微调 backbone 对比。
- 成功案例与失败案例可视化。

## 9. 推荐优先级

建议实现顺序：

1. 真实 FBAA。
2. 真实数据接口。
3. 评估和可视化脚本。
4. 高频分支。
5. 分类头。
6. 压缩鲁棒实验。

FBAA 应该最先做，因为它和题目最贴近，也是最容易讲清楚的核心创新点。
